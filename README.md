# Crestron Home drivers

Two separate products live in this folder. Each has its own solution and `.pkg` output.

| Folder | Product | Package |
|---|---|---|
| `Yamaha` | R-N2000A AV receiver (YXC) | `Yamaha\pkg\Yamaha.RN2000A.Crestron.pkg` |
| `Roon` | Roon Core transport / now playing | `Roon\pkg\Roon.Crestron.pkg` |

Volume stays on the Yamaha driver. Roon is play/pause/skip and now playing.
